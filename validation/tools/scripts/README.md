# Shared Validation Scripts

These scripts are framework-wide helpers and should not be copied into each
case directory.

| Script | Purpose |
| --- | --- |
| `plot_monitor_bulk_change_history.py` | Plot bulk monitor/change histories. |
| `plot_monitor_points.py` | Plot monitor point histories in combined figures. |
| `plot_monitor_points_seperate.py` | Plot monitor point histories in separate figures. |
| `plot_check_mesh.py` | Plot mesh/check output. |
| `rebuild_tavg_from_new_start.py` | Rebuild time-averaged data from a new start point. |
