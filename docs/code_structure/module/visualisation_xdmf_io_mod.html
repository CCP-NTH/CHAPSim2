Low-level XDMF writer helpers for CHAPSim visualisation output.

This module writes the XML fragments that describe Cartesian rectilinear grids, cylindrical curvilinear grids, scalar attributes, and binary data references for ParaView/VisIt-compatible XDMF files.


Uses

    • parameters_constant_mod
    • iso_fortran_env
