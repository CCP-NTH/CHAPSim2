Read and validate the main CHAPSim input file.

This module owns the user-facing input_chapsim.ini interpretation: process switches, geometry, mesh, flow, thermal, MHD, boundary-condition, scheme, I/O, and statistics settings. It also prints readable names for selected integer IDs so run logs are easier to audit.
