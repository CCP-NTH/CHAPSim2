public pure subroutine pchip_node_slopes(x, y, m)

Monotone (Fritsch-Butland) node slopes of y(x) for strictly increasing x: the PCHIP slopes. Interior node: weighted harmonic mean of the adjacent secants when they have the same sign, zero otherwise (local extremum). End nodes: three-point one-sided estimate, limited so the end interval stays shape-preserving (same rule as Fritsch & Carlson 1980 / Moler, Numerical Computing with MATLAB, pchip). The resulting cubic Hermite interpolant preserves monotonicity of the data and stays within adjacent node values. - x, y (in): node abscissae (strictly increasing) and values. - m (out): slopes dy/dx at the nodes.

private subroutine build_pchip_slopes()

Set the PCHIP node slopes d(.)/dh of the non-dimensional table (once, at table load, property_interp = pchip only). Requires h strictly increasing along the T-sorted table, and dT/dh > 0 at every node so that cp = 1/(dT/dh) is finite; stops otherwise.

None

private subroutine ftp_pchip_eval_h(this)

Locate the table interval [h(i1), h(i1+1)] containing this%h (exact comparisons) and evaluate the cubic Hermite interpolants there: y(h) = H00 y1 + H10 dh m1 + H01 y2 + H11 dh m2, s = (h - h1)/dh, H00 = (1+2s)(1-s)^2, H10 = s(1-s)^2, H01 = s^2(3-2s), H11 = s^2(s-1); sets t, d, m, k, sigma_e, b, and cp = 1/(dT/dh) (non-dimensional: with h = (h - h0)/(cp0 T0) and T = T/T0, dT/dh = cp0 dT/dh* = 1/cp). h outside the table is recorded (collective stop by check_property_range) and the end value used; no extrapolation.

Arguments

Type IntentOptional Attributes Name
type(t_fluidThermoProperty), intent(inout) :: this

private subroutine pchip_h_from_t(t, h)

Inverse of the PCHIP T(h): the h with T_cubic(h) = t. The interval comes from the T nodes (T_i = T(h_i), T increasing), the root from a bracketed Newton iteration in s = (h - h1)/dh on [0, 1], falling back to bisection whenever a Newton step leaves the bracket. T_cubic is monotone on the interval, so the root is unique; iteration stops when the bracket is below 4 ulp of s. t outside the table is recorded and the end value used.
