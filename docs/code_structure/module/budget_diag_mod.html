B3.5/B3 conservation diagnostics (opt-in, env CHAPSIM_B3_BUDGET=1). Read-only accumulators of the discrete mass and rho*h budgets, built from the solver's own boundary-face fluxes and the RK3 weights. They never feed back into the solution. Conventions (undimensional): energy: d/dt int(rho h) dV = int R_H dV, R_H = D(-g h_F) + (1/(Re Pr0)) D(kappa_F G T) int R_H dV = sum over boundary faces of (f_out - f_in) dA for a telescoping (CD2) divergence with the solver's cell volumes mass: D g^k = -rho_t^k + c^k (c = closed-domain compatibility correction)
