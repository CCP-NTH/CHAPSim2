public subroutine check_stats_bundle_file_size(dm, group_name, iter, fields)

Stop unless the statistics .bin holds exactly the arrays of the validated field list. Every entry is one full cell-centred (dccc) array, written in list order by stats_bundle_write1/N, and an MPI-IO read past the end of the file is not an error, so a truncated or padded bundle would otherwise be read without notice (same rule as check_bundle_file_size for restart bundles). Rank 0 measures the file and broadcasts the size, so every rank reaches the same verdict. Collective: call on all ranks.

public subroutine store_stats_prev_flow(fl, dm)

B3.5: store u and grad(u) of the current completed state as the previous step of the next full-step pressure-statistics sample. Called after the initial / restart state is set up and at iter == stat_istart (the first sample is taken at stat_istart + 1); later samples update it themselves. A restart therefore needs no extra field: the restart state is the previous completed step of the first step after the restart.
