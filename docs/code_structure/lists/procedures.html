check_thermo_interp_metadata io_restart_mod Subroutine

Restart policy for the property interpolation (all ranks; rank 0 reads and broadcasts, so every rank takes the same decision): record linear -> run linear: allowed; record pchip -> run pchip: allowed; record and run differ: stop; no record (checkpoint written before property_interp existed, i.e. with linear interpolation): allowed for linear, as before; stop for pchip; unreadable record, or domain/iteration not matching the checkpoint: stop. A change of interpolation at a restart is rejected because the stored density and rho_hat belong to the writing mode's property relation: the new mode would relax rho in one step and keep a permanent rho_hat offset. Enthalpy advection (optional fifth line; absent = cd2, which includes every checkpoint written before the key existed), checked after the property interpolation, whose rules above are not affected: same mode: allowed; different mode, enthalpy_advection_restart = strict (default): stop; different mode, allow_switch: allowed with a warning and recorded in the sixth line of later records, unless the statistics would continue across the change (stat_level > 0, iteration > stat_istart, run clock continued): then stop until the statistics window is reset; unrecognised fifth or sixth line: stop. Inverse of the PCHIP T(h): the h with T_cubic(h) = t. The interval comes from the T nodes (T_i = T(h_i), T increasing), the root from a bracketed Newton iteration in s = (h - h1)/dh on [0, 1], falling back to bisection whenever a Newton step leaves the bracket. Records the flow step at which a thermal checkpoint is written ('flow_iteration '). Thermal checkpoints are labelled by tm%iteration, which follows the run clock (chapsim.f90), so the record equals the label. Builds before 2026-10-30 advanced tm%iteration only while the energy equation was solved: with niterthermofirst > niterflowfirst the label was lower than the flow step, and a thermal checkpoint could carry the label of an earlier flow checkpoint with the same stored time; the record lets a restart detect such a pair.
